## Working end to end

- Create, rename, edit, autosave, save now (Ctrl/Cmd+S or click the save status), reopen
- Bold, italic, underline, Heading 1–3, bulleted and numbered lists, undo/redo
- Import `.txt`, `.md` and `.docx` up to 2 MB as new editable documents (supported types are shown in the UI)
- Sharing: owner, add people by email, remove access, plus separate *My documents* and *Shared with me* sections with an Owner column
- Access control on the server (no access = 404) and HTML sanitization on every write
- SQLite persistence across refreshes and restarts
- Validation and readable errors for bad input
- `npm test`: 24 tests

## Partial or not done
